# TheJaypeeCafeGDGproject
A responsive, modern, and interactive web application designed for **The Jaypee Cafe** located at Jaypee Institute of Information Technology (JIIT), Sector 128, Noida.
Built using HTML5, CSS3 styling, and JavaScript

Fully Responsive Layout
Table Reservation System
Warn Aesthetics
Dynamic Menu
Essential info and Contact Details
